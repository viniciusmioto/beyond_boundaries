## Overview

This repository hosts the code, scripts, and notebooks used to analyze international and interdisciplinary collaboration patterns in Brazilian computer science research. By leveraging bibliometric and network analysis methods, the project explores:
- **International Collaboration:** How Brazilian subfields engage with researchers and institutions abroad.
- **Subfield Dynamics:** Variations in collaboration structures among different subfields of computer science.

All materials provided here support reproducibility and further exploration, enabling researchers to extend or adapt the methodology.

---

## Research Questions

The study focuses on answering two primary questions:

- **RQ1:** To what extent are Brazilian subfields collaborating with researchers and institutions in other countries?
- **RQ2:** What are the key differences in collaboration networks across Brazilian subfields of Computer Science?

## Data Description

### Main Data File: `br_publications_meta.csv`

This CSV file includes metadata for academic publications, with columns such as:

| Column Name        | Description                                                                                                     | Example                                                       |
|--------------------|-----------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------|
| `id`               | Unique publication identifier.                                                                                  | `W2928842276`                                                 |
| `doi`              | Digital Object Identifier.                                                                                        | `10.1016/j.patrec.2019.03.022`                                  |
| `title`            | Title of the publication.                                                                                         | `"Publication Title Example"` |
| `publication_year` | Year the publication was released.                                                                              | `2019`                                                        |
| `authorships`      | JSON-formatted list of authors including IDs, names, institutions, and countries.                               | See example below                                             |
| `subfield`         | JSON field indicating the subfield (e.g., `Artificial Intelligence`).                                             | `{"id": "subfields/1702", "display_name": "Artificial Intelligence"}` |
| `cited_by_count`   | Number of citations received.                                                                                     | `8`                                                         |
| `counts_by_year`   | JSON object of yearly citation counts.                                                                           | `{"6_year": 8, "5_year": 96, ..., "0_year": 26}`                |
| `primary_topic`    | Primary research topic (if available).                                                                            | `{'id': 'T10862', 'display_name': 'AI in cancer detection'}`    |

#### Example `authorships` Entry:
```json
[
  {
    "id": "A123456789",
    "name": "Author Full Name",
    "institutions": [{"id": "I12345678", "display_name": "Research Institution Example"}],
    "countries": ["BR"]
  }
]
```

## Collaboration Network Structure

The repository produces co-authorship networks exported in GEXF format. In these networks:
- Nodes represent authors.
- Edges represent co-authorships, with weights indicating the frequency of collaboration.

### Node Attributes

- `label1`: Country code of the primary institution (e.g., BR, US).
- `label2`: Author’s primary subfield (e.g., Artificial Intelligence).

### Edge Attributes
- `weight`: Frequency of collaborations between authors.

### GEXG Snippet
```
<node id="A123456789" label="A123456789">
  <attvalues>
    <attvalue for="0" value="BR" />                 <!-- Country -->
    <attvalue for="1" value="Artificial Intelligence" />  <!-- Subfield -->
  </attvalues>
</node>
<edge source="A123456789" target="A987654321" weight="1" />
```

## Methodology

### Data Collection
**Source:** OpenAlex API provides comprehensive metadata.  
**Focus:** Extracts Brazilian computer science publications (2015–2024) with details on authors, institutions, citations, subfields, and topics.  
**Strategy:** Utilizes API response metadata for aggregate counts and detailed publication metadata for in-depth analyses.  

### Processing
Scripts in `src/data_processing/` perform tasks including:

- **Country-level summaries:** Counting and concatenating publication data across subfields 
- **Metadata aggregation:** Consolidating publication metadata
- **Network construction:** Building and filtering co-authorship networks 
- **Calculate metrics:** Calculating statistics, averages, and network centralization

### Network Construction & Analysis
- **Co-authorship Networks:** Nodes (authors) and edges (collaboration links) are generated based on co-authorship data.
- **Filtering:** Networks are filtered to retain substantial collaborations (e.g., edge weight ≥ 2).
- **Layout:** Gephi (using the Fruchterman-Reingold algorithm) is applied for visualization.

### Visualization
Two parallel visualization paths are used:
- **Jupyter Notebooks:** For generating figures (e.g., subfield percentages, heatmaps, centralization metrics).
- **Gephi:** For detailed network visualizations exported as GEXF and PDF figures.

## Reproducibility Guide

### 1. Environment Setup
Ensure you have Python 3.8+ installed. Install dependencies:
```sh
pip install -r requirements.txt
```

### 2. Execute Data Processing Pipeline
Run the scripts sequentially as follows:
```sh
python src/1_extraction/1_0_extract_publication_summary_of_countries.py
```
- Until the last Python script. Data will be saved to `data/raw/`.

After that, run the processing:

```sh
python src/2_processing/2_0_concat_publications_per_subfield.py
```
- Until the last Python script. Data will be saved to `data/processed/`.


### 3. Run Visualization Notebooks
Launch Jupyter Notebook:
```sh
jupyter notebook
```
Navigate to `src/visualization/` and execute the notebooks in order.
